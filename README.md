# Meow extension


## Описание

Расширение для VS Code: каждые 10 написанных строк кода показывает вашу картинку
в панели рядом с редактором и проигрывает звук. Через 5 секунд панель закрывается.

## Возможности

- Подсчёт новых строк кода во всех открытых файлах
- Показ картинки из `media/image.*` (png, jpg, gif, webp, svg) без потери фокуса в редакторе.
- Проигрывание звука `media/sound.*` (mp3, wav, m4a, aiff)
- Команда «Line Image Reward: Показать картинку сейчас» (⇧⌘P) для проверки.

## Как поменять картинку и звук

Положите свои файлы в папку `media` под именами `image.png` (или `.jpg`, `.gif`, ...)
и `sound.mp3` (или `.wav`, ...). Если файлов с таким именем нет, используются `image.svg` и `sound.wav`.

## Запуск

1. Откройте папку проекта в VS Code и нажмите **F5**.
2. В новом окне создайте файл и напишите 10 строк.
